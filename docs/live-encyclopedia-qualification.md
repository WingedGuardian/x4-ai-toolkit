# Built encyclopedia text observer

Offline source and synthetic behavior qualified; runtime, opening and production integration are unqualified. This is the encyclopedia portion of C-UI-5, not coverage of the map's property pane or all displayed text.

Native source: `menu_encyclopedia.lua` 1478–1526 maps index entry names to text cells; 1609–1704 creates the index, description and detail tables; 1928–1930 publishes their actual widget IDs; 1964 clears the display transition gate. `helper.lua` 3888 records table column count; 4151 assigns `GetCellContent` IDs; 5475 retains `properties.text`; 5520 copies text into the render descriptor. The observer reads these existing properties. It does not execute dynamic text callbacks, query a hidden source catalogue, open menus or infer pixels.

Pure factory dependencies: `menus`, public `current`, UI elapsed `now`, `valid_widget`, `cell_id`, and the existing bounded wire `encode`. `read(section,start)` accepts `index`, `description`, or `detail` and a one-based text-cell offset. Four text cells are returned per call, with the complete selected-table text/static/unknown/nontext/spanned-cell denominator. `dispose()` invalidates future reads. Constructor performs no native call. No writes or action provider are present.

Two reads must agree on typed menu context, frame/table identities, row/cell references, native text widget IDs, static strings and dynamic-function identity. The selected menu must be shown, unminimized and outside display/refresh transition. Dynamic or missing/nonstring text is explicitly `UNKNOWN`; an empty string remains an observed empty string. Unknown context is preserved as typed unknown, never guessed into an actor or macro identity. Menu context does not by itself prove every row describes that selected object. Built offscreen rows remain built model evidence, not visible-pixel evidence.

Bounds: 2048 rows, known native column counts (6/1/5), 4096 text cells, 4096 bytes per static text/context string, four returned text cells and 30000 encoded bytes. Sparse, duplicated, missing or over-bound structures refuse instead of truncating silently. Per-call pagination rereads the live frame; it is not a frozen cross-page snapshot. Consumers must retain context/frame/table/stability evidence and cannot promote assembled pages to an atomic or full encyclopedia census.
