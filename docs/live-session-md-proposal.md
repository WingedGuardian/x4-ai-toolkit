# Public session MD proposal generator

scripts/live_session_md.py is a pure generator promoted from the reviewed private preparation. It writes nothing. Its generated MD owns only session/generation tokens and bounded handshake/state blackboards; it contains no scenario logic or game data. The helper manifest and UI load-order changes remain a separate reviewed application proposal.

The source bytes, normalized from CRLF to LF, are included in the revision identity. This promotion adds that normalization so Windows and Unix checkouts agree. Other source changes change the revision. Build the bundle and host expectations from the same generator receipt; do not assume a permanent constant.

This is schema-equivalent reuse, not a new compile or runtime check.

Native cue ordering, blackboard transfer and invalidation still require runtime controls. The MD world token is not proof of save lineage. Every new load must acquire a new host session nonce; an explicit same-world UI reconnect may resume only the existing session. No game launch, XML application or deployment is performed by this generator.
