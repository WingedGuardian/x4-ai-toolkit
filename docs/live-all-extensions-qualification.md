## Historical eight-extension checkpoint

This is an offline constructor/lifecycle test of the actual source-bound public
bundle and all eight real generated extension loaders in one LuaJIT VM:
placement, trader/text, rooms, topology, conversation, persistence, capture and
orbit. No module factories are replaced. Only native game boundary functions,
event registration and delayed scheduling are synthetic. Native game calls are
forbidden and counted. The loaders and MD candidates remain in memory.

Conversation registers two providers, so the eight public extensions declare
nine providers. The native bundle adds one. A ninth synthetic fixture descriptor
adds one more to test the required catalogue occupancy without distributing or
importing private ROR code. This does not qualify the actual private fixture.

The tests verify exact provider revisions through the actual SDK registry with
the public session deliberately unready. Requests remain unknown; no prepared
request is executed, and unknown is not readiness. Constructor tests check shared
FFI declarations, exact event registration, same-VM owner reconstruction, late
callback inertness after disposal, partial attachment cleanup and sticky failure.
The five constructor event subscriptions are checked exactly. Conversation and
topology subscribe only on their first `begin`; those deferred subscriptions are
not exercised by this constructor-only test. Their SDK provider registrations
are checked without dispatching actions.
Delayed callbacks are stored and not fired for a live owner. Retired callbacks
may be invoked only to confirm that they perform no native work.

The pure composition validates output hashes and loader order. Every consumed
own-code input is hashed before generation and rechecked after the test module.
This evidence does not qualify MD wiring, Windows/native ABI, actual gameplay,
renderer visibility, action results, save safety or runtime campaign acceptance.
